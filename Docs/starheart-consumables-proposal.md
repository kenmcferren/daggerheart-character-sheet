# Starheart Consumables: proposed rename and condense (for owner approval)

- Cyphers (1-30): unchanged (names and text).
- Gadget, Ordnance, Stim: new sci-fi names, tighter text. Numbers, dice, ranges and game terms (Hope, Hidden, Vulnerable, Ablaze...) are untouched.
- Pact Worlds hooks used in names: Castrovel (plants, bio-tech), Eox (toxins, death-tech), Akiton (red desert world), Absalom Station, the Stewards (peacekeepers), Pharasma's church (death rites), the Drift.
- Stim choosable at creation (per the owner): 1-6, 8, 9, 10. Stim 7 (Antitox Capsule) is not offered.
