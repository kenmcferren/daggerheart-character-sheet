# Sheet Layout Proposal (Series 4, step 1)

Status: **approved by owner.** Decisions: 1 A (two pages + overflow); 2 square boxes for primary trackers (HP, Stress, Hope, armor slots, frame trackers), open circles for domain/class/subclass trackers; 3 A (Letter only); 4 A (full card text); 5 B (bundled open-license font, family still to pick).

## Principles
- Rules text only, no flavor (per project rule). Wording verbatim from packs.
- Prints in grayscale on plain paper; no filled backgrounds, thin rules, black text.
- Every value comes from `deriveStats` / the character's chosen pack entries. Nothing typed twice.
- Blank boxes for things the player fills in play (current HP/Stress/Hope marks, gold, notes).
- Page size: US Letter, 0.5" margins (A4 selectable later). Portrait.

## Pages
- Page 1 (front): identity, traits, defense, health, weapons, class/heritage features.
- Page 2 (back): domain cards, experiences, inventory, downtime moves, frame/supplement trackers and rules, notes.
- Overflow page(s) added only if text does not fit (no shrinking below 8 pt).

## Decisions for the owner
1. Page count: (A) fixed two pages, overflow page if needed, or (B) one page only with smaller text?
2. Trackers: (A) drawn as open circles, filled in by pen, or (B) as square boxes?
3. Paper: (A) Letter only for now, or (B) Letter plus A4 toggle now?
4. Domain cards: (A) full rules text on the sheet, or (B) name and recall cost only (players keep the cards)?
5. Fonts: (A) built-in Helvetica (no files, simplest), or (B) a bundled open-license font (nicer, adds files)?

Recommendation: 1 A, 2 A, 3 A, 4 A, 5 A (upgrade fonts later if wanted).
